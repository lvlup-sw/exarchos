# Source Material

These files are the reports, analyses, principles, and designs merged into the
canonical [`../unified-remediation-plan.md`](../unified-remediation-plan.md).
They provide rationale, detailed requirements, fixtures, and acceptance
criteria; they do not define separate implementation sequences.

| File | Contribution to the unified plan |
|---|---|
| `phase-gate-v212-dogfood.md` | Runtime failures CB-1 through CB-9, documentation defects DOC-1 through DOC-6, and trace evidence |
| `phase-gate-v212-dogfood-remediation.md` | Structural root causes, Tracks 0-5, containment batch, benchmark plan, and 17 dogfood exit criteria |
| `structural-principles-codebase-assessment.md` | Seven-principle rubric and original seam analysis |
| `agent-principles.md` | Structural design principles used to organize closure proofs |
| `phase-gate-redesign-strategy.md` | Research behind evidence-backed admission |
| `phase-gate-transition-admission-roadmap.md` | Roadmap-level admission architecture |
| `phase-gate-transition-admission.md` | Full admission requirements and 53-task technical design |
| `phase-gate-v212-proof-substrate.md` | Detailed proof-substrate design and implementation decomposition |
| `structural-closure-audit-spec.md` | Scope and requirements used to produce the baseline audit |
| `*-traceability.md` | Source requirement-to-task coverage matrices |
| `diagrams/` | Structural-principle diagrams packaged with the original research |

Source task identifiers remain useful for finding detailed acceptance criteria.
The unified plan's work packages own actual sequencing.
